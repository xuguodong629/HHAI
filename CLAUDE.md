# Mandatory HHAI Preflight

Before any HHAI development, read [`CONSTITUTION.md`](./CONSTITUTION.md) in full. It is the sole highest-level design authority. Then read the affected package's local README and applicable HHAI-Standards rules. Do not infer architecture from chat history or create conflicting design documents.
