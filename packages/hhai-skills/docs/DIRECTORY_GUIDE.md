# V2.0 目录指南

- `skills/`：RBOS、BOS、COS、UOS、RWOS、DOS 和 Industry Skill Packages。
- `prompts/`、`playbooks/`、`sop/`、`cases/`、`metrics/`、`dashboards/`：可复用业务中心。
- `graphs/`、`schemas/`：知识图谱和结构化契约。
- `runtime/`：注册表、路由、别名、能力契约和版本。
- `shared/`：公共资源、模板和工具知识。
- `index/`：SUMMARY、Skill 索引、导航和知识图谱导出。
- `assets/`、`docs/`：资源和仓库规范。
