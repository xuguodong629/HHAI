# RBOS·Sales-Growth·销量增长客单价提升

## 定义

RBOS·Sales-Growth·销量增长客单价提升是面向家电经营组织的正式业务能力，负责把“销量增长客单价提升”从问题识别、目标设定、执行管理到结果复盘形成可审计的闭环。该 Skill 的边界是Sales-Growth相关决策，不替代财务审批、合同审批或专业法律意见。

## 业务价值

通过统一口径、责任人、节奏和证据链，减少依赖个人经验的判断，使经营动作能够被比较、复盘和持续优化。

## 使用场景

适用于Sales-Growth的年度规划、月度经营、专项战役、异常诊断和管理复盘。当输入数据不完整、口径冲突或涉及重大资源承诺时，必须先进入人工复核。

## 输入与输出

输入包括经营目标、时间范围、组织层级、商品/客户/渠道范围、历史结果、资源约束和责任人。输出包括问题判断、目标口径、行动清单、指标看板、风险记录和复盘结论。

## 核心模型

采用“现状基线—差距拆解—关键杠杆—责任到人—周期复盘”模型。先锁定同一统计口径，再将结果指标拆解为过程指标，优先选择少量可控杠杆，最后用事实证据判断动作是否有效。

## KPI

核心指标包括结果达成率、过程完成率、预测偏差率、投入产出比、异常关闭率和复盘完成率。指标必须同时记录目标值、实际值、差异值、数据来源、统计周期和责任人。

## SOP

1. 明确经营问题、范围和决策时限。
2. 校验数据口径、权限和历史基线。
3. 找出差距及其可控原因，形成优先级。
4. 制定动作、资源、负责人和完成期限。
5. 按日/周/月节奏跟踪指标与异常。
6. 复盘结果，沉淀有效做法并关闭未解决风险。

## Checklist

- [ ] 目标、范围、周期和责任人已确认。
- [ ] 指标定义、数据来源和计算方式已记录。
- [ ] 关键假设和资源约束已显式列出。
- [ ] 每个动作都有负责人和截止时间。
- [ ] 异常有升级条件和处理记录。
- [ ] 结论有数据证据并经过业务负责人确认。

## Prompt

你是 HHAI 的Sales-Growth负责人。请围绕“销量增长客单价提升”读取已授权的经营数据，先说明口径和缺失信息，再按现状、差距、原因、动作、KPI、风险和复盘节奏输出方案。不得编造数据；无法验证的结论必须标记为待确认。

## 案例

当一个区域在Sales-Growth中出现结果低于目标时，先按统一周期拆分到组织、门店、渠道、品类或流程节点，再选择一个可控杠杆进行小范围执行。执行结束后对比基线、目标和实际结果，若没有证据证明改善，应保留原判断为未验证并进入下一轮复盘。

## AI 调用关系

AI 可负责数据整理、差异计算、异常聚类、会议纪要和行动追踪；涉及价格承诺、人员处理、财务支付、客户权益或外部发布时，AI 只能提供建议，必须由授权人员确认。
